02 · Before frameworks

Programming foundations

Build a strong base in how programs work before depending on libraries or AI-generated code.

1

JavaScript fundamentals

Variables, types, operators, conditionals, loops, functions, arrays, objects, scope, closures, modules, error handling.

  • Understand value vs. reference
  • Use array methods and object transformations
  • Write reusable functions
  • Read stack traces and debug in DevTools
2

Modern asynchronous JavaScript

Promises, async/await, fetch, event loop basics, JSON, HTTP requests, loading and error states.

  • Call a public REST API
  • Handle timeouts and failed requests
  • Understand concurrency at a basic level
3

Developer workflow

Terminal basics, npm, package.json, environment variables, Git, GitHub, branches, commits, pull requests.

  • Use Git without losing work
  • Read package and build errors
  • Write a useful README
Foundation checkpoint: Build a small JavaScript app that fetches data from an API, displays results, validates user input, and handles loading, empty, and error states.

04 · Application engineering

Backend, APIs, databases & security

Node.js & Express

  • Node runtime, npm and modules
  • REST API design and HTTP status codes
  • Controllers, services and middleware
  • Validation, error handling and logging
  • Pagination, filtering and rate limiting

Databases & data modelling

  • SQL fundamentals and relational design
  • MongoDB documents, indexes and queries
  • Schema validation and migrations
  • Transactions, consistency and query performance
  • Choose SQL or NoSQL based on the data model

Authentication & security

  • Password hashing and session/JWT concepts
  • Authorization and role checks
  • CORS, input validation and secure headers
  • Keep API keys on the server
  • Protect user data and tenant boundaries

Testing & API contracts

  • Unit, integration and end-to-end tests
  • Mock external model calls
  • OpenAPI or clear API documentation
  • Test invalid inputs and failure paths
  • Validate AI output before using it

Deployment & operations

  • Environment-based configuration
  • Docker fundamentals
  • CI/CD and deployment pipelines
  • Logs, metrics, tracing and alerts
  • Secrets management, backups and rollback

Architecture as needed

  • Monolith first; clear module boundaries
  • Caching and background jobs
  • Queues and event-driven processing
  • Microservices only when justified
  • Resilience, retries and idempotency
05 · AI application engineering

From API calls to useful AI systems

Learn AI concepts through application development. You do not need to train a foundation model to build useful AI products.

1 LLM and generative AI fundamentals

Understand

  • Tokens, context windows and model limits
  • System/user messages and prompt structure
  • Temperature and output variability
  • Hallucinations, knowledge limits and latency
  • Embeddings at a conceptual level

Build

  • A text summarizer
  • A structured information extractor
  • A response formatter using JSON schema
  • A UI that handles streaming and errors
2 LLM APIs with JavaScript / TypeScript

Learn

  • Call a model provider from a Node.js server
  • Secure API keys in environment variables
  • Stream responses to the frontend
  • Handle quotas, rate limits, retries and timeouts
  • Track token usage and cost

Build

  • AI chat interface in React
  • Backend model gateway
  • Conversation history with clear data rules
  • Provider abstraction for switching models
3 Prompt design and structured outputs
  • Define the task, context, constraints and expected format
  • Use examples only when they improve consistency
  • Prefer schema-constrained outputs for machine-readable data
  • Validate output and handle malformed responses
  • Test prompts against a representative set of inputs

Project: A resume or document analyzer that returns validated structured data rather than a loose block of text.

4 Tool calling and AI agents

Core concepts

  • Tools are ordinary functions exposed to a model
  • Validate every tool argument
  • Apply permissions before executing actions
  • Use bounded steps, timeouts and clear stop conditions
  • Keep a trace of tool calls and outcomes

Project ideas

  • Documentation search assistant
  • Issue triage assistant
  • Read-only GitHub repository helper
  • Human-approved code change workflow
Safety rule: Never give an agent unrestricted access to secrets, shell commands, repositories, or production systems. Use least privilege, sandboxing, audit logs, and explicit approval for consequential changes.
5 RAG — Retrieval-Augmented Generation

Learn

  • Document parsing and chunking
  • Embeddings and vector similarity
  • Vector stores and metadata filters
  • Keyword + semantic/hybrid retrieval
  • Reranking, citations and source grounding

Build

  • Upload and index documents
  • Search relevant chunks for a question
  • Answer using retrieved sources
  • Show source citations in the UI
  • Respect document access permissions

RAG is useful when an application needs to answer from a specific knowledge base. It does not guarantee correctness; retrieval quality and answer grounding must be evaluated.

6 Memory, workflows and orchestration
  • Distinguish short conversation context from durable user memory
  • Persist only necessary data with clear retention rules
  • Build predictable multi-step workflows before adding agent autonomy
  • Use queues for long-running work and resumable jobs
  • Make operations idempotent and recoverable
7 Evaluation, reliability and cost
  • Create test cases for quality, safety, edge cases and regressions
  • Measure retrieval relevance and groundedness for RAG
  • Evaluate tool selection and successful task completion for agents
  • Compare model quality, latency and cost
  • Use rate limits, caching where appropriate, and budget controls
  • Monitor failures and provide a graceful fallback
06 · Build evidence of skill

Project-based learning path

Build in increasing complexity. Each project should have a README, screenshots, setup instructions, tests where appropriate, and a deployed demo when practical.

Foundation

01 · JavaScript API explorer

Search and filter data from an external API. Add form validation, loading and error states, and responsive layout.

Demonstrates: JavaScript, DOM, HTTP, debugging.

Frontend

02 · React productivity app

Build a reusable component system with routing, TypeScript, forms, API integration and automated tests.

Demonstrates: React, TypeScript, UI engineering.

Full stack

03 · Secure CRUD application

Create a Node.js API, database schema, authentication, role-based authorization, validation and deployment.

Demonstrates: backend, data modelling, security.

LLM app

04 · AI learning assistant

Connect a React interface to a server-side LLM API. Add streaming, structured output, error handling and usage tracking.

Demonstrates: LLM integration and production basics.

RAG

05 · Document question-answering app

Index a set of documents, retrieve relevant passages, answer with citations and block access to unauthorized sources.

Demonstrates: embeddings, retrieval, grounding and evaluation.

Capstone

06 · AI developer assistant

Build an assistant that searches project documentation, explains code, proposes patches, runs tests in a restricted environment and asks for approval before applying consequential changes.

Demonstrates: tool calling, agent workflow, sandboxing, Git integration and evaluation.

Portfolio standard: Explain the problem, architecture, key trade-offs, security decisions, evaluation method, known limitations, and what you would improve next. A working, well-documented project is stronger evidence than a long list of tools.

For a JavaScript web developer: prioritize JavaScript → React → TypeScript → Node.js → databases and authentication → LLM APIs → RAG → tool calling and agents → evaluation, security and deployment. Learn Python later only if your chosen work needs data science, model training or Python-specific libraries.
